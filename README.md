# svg-editor

CLI SVG editor — PJ1 Phase 1. TypeScript, object-oriented, zero runtime dependencies.

```bash
npm install
npm run cli                                   # interactive, prompt: svg>
node dist/src/main.js < examples/flowchart.txt  # replay a script (after a build)
npm test                                      # all automated tests
```
